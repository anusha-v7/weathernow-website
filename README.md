# 🌦️ WeatherNow – Real-Time Weather Dashboard

A modern, responsive weather dashboard built using **HTML, CSS, and JavaScript** that fetches and displays real-time weather information using the Open-Meteo REST API.

This project was developed as part of the **Auspify Technologies Frontend Development Internship – Task 4**.

## 🚀 Features

- **City Search:** Search for weather information in cities across the world.
- **Real-Time Weather:** Displays current temperature and weather conditions.
- **Weather Details:** Humidity, wind speed, atmospheric pressure, visibility and UV index.
- **Hourly Forecast:** Displays upcoming hourly weather information.
- **5-Day Forecast:** Provides minimum and maximum temperatures with weather conditions.
- **Current Location:** Fetch weather information using browser geolocation.
- **Temperature Conversion:** Switch between Celsius and Fahrenheit.
- **Recent Searches:** Keeps track of the five most recently searched cities using Local Storage.
- **Dynamic Weather Icons:** Displays icons based on weather conditions.
- **Responsive Design:** Optimized for desktops, tablets and mobile devices.
- **Error Handling:** Handles invalid city searches, network errors and API failures.

## 🌐 API Integration

This application uses the Open-Meteo API.

- **Geocoding API:** Converts city names into geographical coordinates.
- **Weather Forecast API:** Retrieves current weather, hourly forecasts and daily forecasts.

API Documentation: https://open-meteo.com/

No API key is required for standard non-commercial use.

## 💻 How to Run Locally

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension if it is not already installed.

4. Open `index.html`.

5. Right-click and select **Open with Live Server**.

6. Search for any city and explore its weather information.
