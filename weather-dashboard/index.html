About WeatherNow & Project Architecture

Auspify Technologies Internship Project Brief

WeatherNow is a modern, responsive SaaS-style weather dashboard built using pure HTML5, CSS3, and Vanilla JavaScript (ES6+). Phase 2 integrates live real-time weather information using the Open-Meteo Geocoding & Forecast REST APIs.

Phase 2 REST API Architecture (Implemented)

  • Open-Meteo Geocoding API: Converts searched city names worldwide (e.g. Bengaluru, Bellary, Mumbai, London, New York, Tokyo) into precise latitude and longitude coordinates.
  • Open-Meteo Forecast API: Asynchronously retrieves current atmospheric conditions, 24-hour hourly projections, and 5-day daily forecasts.
  • Asynchronous JS: Implemented via fetch(), async/await, and try/catch blocks with thorough HTTP status validation.
  • WMO Weather Code Mapping: Reusable function maps WMO codes (0–99) to readable descriptions (Clear Sky, Partly Cloudy, Drizzle, Rain, Thunderstorm, Snow) and matching day/night SVG icons.
  • Dynamic Timezone Clocks: Computes the selected city's native local date and digital time using Open-Meteo's IANA timezone string.
  • Instant Unit Conversion: Converts between °C and °F dynamically without redundant network roundtrips.
// Open-Meteo REST API Endpoints in script.js:
GET https://geocoding-api.open-meteo.com/v1/search?name={city}&count=10&language=en&format=json
GET https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}&current=...&hourly=...&daily=...&timezone=auto

Zero Framework Compliance

Built strictly without React, Vue, Angular, or external UI runtimes. Works out of the box with VS Code Live Server and modern web standards.
